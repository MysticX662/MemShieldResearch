# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability or potential threat vector within this repository or research implementation, please report it responsibly.

- **Email**: Security research & vulnerability inquiries can be directed to the repository maintainer via [https://usefinora.com/about](https://usefinora.com/about).
- **Response Time**: We aim to acknowledge vulnerability disclosures within 48 hours.

Please do not open public issues for undisclosed security vulnerabilities.
